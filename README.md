# Mājas skola

Sākuma projekts ar trim demonstrācijas skatiem: **Marka skola**, **Samantas skola** un **Vecāka panelis**.

## Pašreizējais posms
- Viena statiska latviešu valodas sākuma lapa (`index.html`).
- Ir tikai navigācijas un sadaļu maketi.
- Nav autentifikācijas, datubāzes, skolēnu datu un īstas progresa uzskaites.

## Nākamie posmi
1. Izvēlēties autentifikācijas un datubāzes risinājumu (piemēram, Firebase vai Supabase).
2. Ieviest vecāka kontu, bērniem atsevišķu piekļuvi un servera pusē pārbaudītas tiesības.
3. Pievienot mācību priekšmetus, uzdevumus, treniņus un rezultātus.
4. Ieviest datu eksportu un regulāras rezerves kopijas.

## Datu drošība
Šis repozitorijs ir publisks. Nekad nepievienot paroles, privātās atslēgas, bērnu personas datus vai īstos rezultātus. Pirmajā versijā dati netiek glabāti.

## Priekšskatījums
Atveriet `index.html` pārlūkā. Publicēšanu ar GitHub Pages var ieslēgt vēlāk.
